API Guide

How to call this API from your own code, in any language or tool.

Two ways to authenticate

Pick whichever fits your use case — both work on every endpoint.

Access token (JWT)

Best for an app where a user logs in and stays active for a session. Expires in ~1 hour; refresh to get a new one.

Authorization: Bearer <access_token>

API key

Best for a script or integration that runs unattended for a long time. Never expires, but only works against the resource it was scoped to.

X-API-Key: <your_key>

1. Get an access token

Exchange your username and password for a token pair — or just copy the one generated above.

curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/token/ \
  -H "Content-Type: application/json" \
  -d '{"username": "your_username", "password": "your_password"}'

2. Make a request

curl

curl {{ request.scheme }}://{{ request.get_host }}/api/reports/?type=LOST \
  -H "Authorization: Bearer <access_token>"

Python (requests)

import requests

headers = {"Authorization": "Bearer <access_token>"}
res = requests.get("{{ request.scheme }}://{{ request.get_host }}/api/reports/", headers=headers)
print(res.json())

JavaScript (fetch)

fetch("{{ request.scheme }}://{{ request.get_host }}/api/reports/", {
  headers: { "Authorization": "Bearer <access_token>" }
})
  .then(res => res.json())
  .then(data => console.log(data));

Using an API key instead

curl {{ request.scheme }}://{{ request.get_host }}/api/reports/mine/ \
  -H "X-API-Key: <your_reports_scoped_key>"

3. Create a report

curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/reports/ \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "report_type": "LOST",
    "item_name": "Black wallet",
    "description": "Leather wallet with student ID inside",
    "category": 1,
    "color": "Black",
    "location": "Main Library",
    "date": "2026-09-20"
  }'

The user and status fields are set automatically — don't send them.

4. Refresh an expired token

curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/token/refresh/ \
  -H "Content-Type: application/json" \
  -d '{"refresh": "<refresh_token>"}'
